## 📚 About

This repository contains my personal journey through **"Hands-on Machine Learning with Scikit-Learn, Keras, and TensorFlow"** by Aurélien Géron - one of the most comprehensive and practical machine learning books available.

Each chapter includes code implementations, exercises, and personal notes as I work through the concepts and techniques presented in the book.

## 🎯 Learning Objectives

- Master fundamental machine learning concepts
- Implement ML algorithms from scratch and using popular libraries
- Build and train neural networks with Keras and TensorFlow
- Apply best practices in model development and deployment
- Gain hands-on experience with real-world datasets

## 🚀 Getting Started

### Prerequisites

```bash
Python 3.8 or higher
pip or conda package manager
```

### Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/Hands-on-Machine-Learning-with-Scikit-Learn-Keras-Tensorflow.git
cd Hands-on-Machine-Learning-with-Scikit-Learn-Keras-Tensorflow
```

2. Create a virtual environment (recommended)
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

3. Install required packages
```bash
pip install -r requirements.txt
```

### Running the Code

Navigate to any chapter directory and open the Jupyter notebooks:

```bash
cd Chapter-XX-Topic-Name/
jupyter notebook
```
